# GameVault – Каталог за компютърни игри (Задание №4)

Уеб платформа с каталог, търсачка, потребителски профили и оценки за компютърни игри.
Данните се съхраняват в **SQLite** база данни, а сървърът е на **Node.js** без външни зависимости.

## Стартиране
Изисква се **Node.js 22.13 или по-нов** (https://nodejs.org).

```bash
npm start
```
После отворете **http://localhost:3000**. Не е нужно `npm install`.
При първо стартиране базата се създава и се попълва автоматично с 12 игри.

Демо потребител: `demo1` / `demo123` (има и demo2 … demo10).
Начално състояние на базата: `npm run reset-db`, после `npm start`.

## Функционалности
- Каталог: заглавие, производител, година, упътване за инсталация/геймплей, рейтинг, изображение
- Търсене по име и филтри по производител и минимален рейтинг (заявка към базата)
- Регистрация, вход и изход; паролите се пазят хеширани (scrypt), сесията е в HttpOnly cookie
- Оценяване 1–5 от влезли потребители (една оценка на потребител за игра, може да се променя или премахва)
- Рейтингът на играта е средната стойност на всички оценки в базата
- Адаптивен дизайн (Mobile-First), lazy loading и кеширане на снимките

```

├── server/                    ── BACKEND
│   ├── config.js              – настройки (порт, пътища, ключ за сесиите)
│   ├── routes.js              – таблица с API маршрутите
│   ├── controllers/
│   │   ├── authController.js  – регистрация, вход, изход, профил
│   │   └── gamesController.js – игри, филтри, оценки
│   ├── models/                – SQL заявки към базата
│   │   ├── userModel.js
│   │   ├── gameModel.js
│   │   └── ratingModel.js
│   ├── services/auth.js       – хеширане на пароли, подписани токени
│   ├── db/
│   │   ├── schema.sql         – структура на таблиците
│   │   ├── database.js        – връзка с базата
│   │   └── seed.js            – примерни данни
│   └── utils/http.js          – JSON, cookies, статични файлове
└── public/                    ── FRONTEND
    ├── index.html
    ├── css/style.css
    ├── js/
    │   ├── utils.js           – помощни функции
    │   ├── api.js             – заявки към сървъра
    │   ├── auth.js            – вход / регистрация (интерфейс)
    │   ├── ui.js              – визуализация
    │   └── app.js             – търсене, филтри, събития
    └── images/                – корици на игрите (напр. hades.jpg)
```
Слоеве на сървъра: **routes → controllers → models → база данни**.

## База данни
```
users ──< ratings >── games >── studios
                        │
                        └──< game_genres >── genres
```
| Таблица | Съдържание |
|---|---|
| users | потребителско име, имейл, хеш на парола |
| studios | производители |
| genres | жанрове |
| games | заглавие, производител, година, упътване, снимка |
| game_genres | връзка игра ↔ жанр (много към много) |
| ratings | оценка 1–5 (уникална двойка потребител + игра) |

## API
| Метод | Адрес | Описание | Изисква вход |
|---|---|---|---|
| GET | /api/games?search=&studio=&minRating= | списък с търсене и филтри | не |
| GET | /api/games/:id | една игра | не |
| GET | /api/studios | производители | не |
| GET | /api/stats | обща статистика | не |
| POST | /api/auth/register | регистрация | не |
| POST | /api/auth/login | вход | не |
| POST | /api/auth/logout | изход | не |
| GET | /api/auth/me | текущ потребител | не |
| PUT | /api/games/:id/rating | оценка `{ "value": 1-5 }` | да |
| DELETE | /api/games/:id/rating | премахване на оценка | да |

## Добавяне на игра
Добавете обект в масива `GAMES` във `server/db/seed.js`, сложете снимка в `public/images/`,
изпълнете `npm run reset-db` и стартирайте отново.
Ако снимката липсва, автоматично се показва генерирана корица.

## Сигурност (кратко)
Пароли със scrypt и сол · подписани сесии (HMAC) · подготвени SQL заявки (без SQL инжекция) ·
екраниране на HTML (без XSS) · защита от излизане извън папката `public/` · валидация на входа.
За публикуване в интернет добавете HTTPS (флаг `Secure` на cookie) и ограничение на опитите за вход.
